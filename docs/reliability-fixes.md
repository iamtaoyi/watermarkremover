# 任务、计费和会话修复

## 当前行为

- 单文件处理、单任务开始、批量开始统一校验归属和余额，再扣费入队。普通模式按服务端核实的时长向上取整，超清乘 2；余额不足返回错误，不自动改变处理模式。管理员代为启动任务时，扣管理员余额，退款退给实际付款人。
- 文件内容仍可按 MD5 秒传；任务和产物只在同一用户、相同操作、模式、模型、区域与超清选项下复用。成功任务的参数不会被批次修改接口改写。
- 排队任务显示为排队。单个和批量取消都会移出队列、立即退款，重复取消不会重复退款。正在停止的 worker 退出前不能重新开始，以免旧执行覆盖新执行。
- 超清期间保留 processing 状态；结果写入后才发布 succeeded。超清任务 ID 会保存，服务重启后接管原任务。云端超清失败时仍沿用原有的去字幕结果回退及不退超清费用规则；该结果不会作为成功超清产物复用。
- 服务端会话续期同时刷新 Cookie。页面刷新会话信息时同步更新倒计时。
- 畸形 Cookie 会被忽略，畸形路径返回 400；请求解析和鉴权均受异常边界保护。
- 上传取消和超时会结束 Promise、释放上传名额，取消后的文件不会继续提交上传或加入批次。

## 时长探测依赖

服务端需要 FFmpeg 提供的 `ffprobe`。不使用客户端声明的时长计费，也不会在探测失败时按 1 秒兜底。

- Ubuntu / Debian：`sudo apt-get install ffmpeg`
- macOS（已有 Homebrew）：`brew install ffmpeg`
- 其它系统：安装 FFmpeg 并确保 `ffprobe` 在服务进程的 PATH 中，或在环境变量中设置 `FFPROBE_PATH=/absolute/path/to/ffprobe`。

部署脚本已将 ffmpeg 加入系统依赖，将 media.mjs 加入发布文件。部分 RPM 发行版默认仓库不提供 FFmpeg，需要先配置该发行版支持的仓库。缺少 ffprobe 返回 503；文件没有可确认时长的视频流或探测失败返回 422，均不提交云端任务、不扣费。

已有文件会在首次使用时探测并缓存可信时长。历史 MD5 产物索引不会作为新缓存命中；新任务完成后写入带用户和处理参数的新索引。历史批次若引用其它用户的任务，会返回 409 并要求重新创建；历史无主任务仅管理员可访问。已有账户和积分账本保留，不自动修改过去的扣费记录。

## 验证

运行 `npm test`。测试启动临时目录下的独立服务和本地模拟云接口，不使用真实 API 密钥、不访问付费云接口、不修改工作目录内的 data。

覆盖畸形请求、Cookie 续期、三个启动入口的计费、伪造客户端时长、无效媒体拒绝、实际付款人退款、跨用户及编码路径越权、模式/超清缓存隔离、排队取消、超清处理中重启、嵌套响应解析、上传取消及前端会话倒计时。

HTTP 集成测试使用模拟的 ffprobe 可执行文件，以确定性的时长验证计费规则；真实视频容器兼容性及云端接口连通性需要部署环境另行验证。
